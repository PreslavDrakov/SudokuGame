# SudokuGame
This project is build using python. For the GUI is used turtle library. The user can choose a difficulty(easy, normal or hard) and variant of sudoku(4x4, 9x9 or 16x16). There are two options for using the app one is to place numbers on a board and let the computer to solve the sudoku using backtracking algorithm. The other option for the user is to solve a computer generated sudoku.
